# Brand Guidelines — Tanafus Center

Identitas visual resmi Tanafus Center. Semua UI, email, export PDF,
dan materi lain HARUS mengikuti pedoman ini.

---

## 1. Identitas

| Item | Nilai |
|------|-------|
| Nama brand | **Tanafus Center** |
| Nama pendek (UI/space sempit) | Tanafus |
| Tagline (opsional) | "Membina Bacaan Al-Qur'an dengan Terukur" |
| Karakter brand | Hangat, modern, terpercaya, ramah keluarga |

Kapitalisasi: "Tanafus Center" (T dan C besar). Jangan TANAFUS,
tanafus, atau TanaFus.

---

## 2. Palet Warna

| Token | HEX | Peran |
|-------|-----|-------|
| `orange-500` | **#FF7A00** | ACCENT UTAMA (ciri khas). CTA, tombol utama, highlight, aktif state, progress. |

| `orange-600` | #E66E00 | Hover state tombol primary (oranye ditekan sedikit lebih gelap). |
| `cream-100` | **#EFE5DC** | Background section sekunder, kartu lembut, header halaman. |
| `cream-50` | **#FBFEFB** | Background utama halaman (nyaris putih dengan nuansa hangat). |
